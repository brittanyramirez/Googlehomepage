# Google HomePage

## 📌 Project Overview

This project is a beginner level recreation of the Google homepage built using HTML, CSS, and JavaScript. It focuses on strengthening core front-end skills by structuring the layout with semantic HTML, styling the interface to closely match Google’s design using CSS, and adding basic interactivity with JavaScript.

The search feature captures user input and displays it in an alert when the search button is clicked, demonstrating fundamental DOM manipulation and event handling. This project highlights foundational web development concepts and attention to layout and design detail.
